# Decision log (orchestrator)

Brief said: no questions, resolve every ambiguity and log it.

1. **Motion engine.** The reference pages do not expose GSAP timelines: they run Webflow IX2 interactions, Lottie (bodymovin) loops, Swiper, `<video>` loops and a small bundled gsap chunk on the home page. All motion is re-implemented in GSAP + ScrollTrigger here, taking triggers, durations, easings and staggers from the reference's IX2 data / scripts (downloaded to `/home/claude/ref/<page>/js-*`).
2. **Copy conflict.** The brief says both "Lorem Ipsum" and "copy from rebirthwebdesign.com.au". Resolution: Rebirth copy (saved in `content/rebirth-copy.md`) is fitted to each section first; Lorem Ipsum only fills slots with no fitting source text. Text length is kept close to the reference so line breaks and block heights match.
3. **Style doc placement.** `DESIGN.md` → project root (governs every design decision). `theme.css` → `src/styles/theme.css` (Tailwind v4 `@theme`, imported right after `tailwindcss`). `variables.css` → `src/styles/variables.css` (`:root`). `tokens.json` → `src/tokens/tokens.json` (source of truth for token values). All four are unmodified copies.
4. **Fonts.** ABC Ginto Discord / Nord are proprietary. The substitutes named in DESIGN.md (Unbounded for Nord, DM Sans for the body face) are self-hosted and registered under the documented family names so the tokens stay untouched. Glyph widths therefore differ from the reference.
5. **Brand assets.** No Discord logo, wordmark, mascots/characters (Wumpus, Clyde, etc.), product screenshots or any file downloaded from the reference is used. The site is branded Rebirth Web Design with original graphics, per the brief's "custom graphics" + "Unsplash only" rules.
6. **QA tooling.** Playwright (headless Chromium in the build sandbox) is used for all reference comparisons instead of Claude in Chrome — same result, no load on the team's browser.
7. **What "replica %" measures.** Copy, photos, illustrations and fonts are different by brief, so a pixel diff against the reference cannot approach 99%. Fidelity is measured on what the brief says must match: section geometry (positions/sizes at 1680px), typography metrics, colour, radii, spacing and motion parameters.
8. **Viewport.** 1680px desktop is the measured target (the style docs' viewport). Layouts must also hold at 1280, 768 and 390 following the reference's own responsive behaviour.
9. **Careers.** The whole job-listing section headed "DON'T JUST IMAGINE THE FUTURE OF GAMING — BUILD IT WITH US." (reference y≈3172–9889) is omitted as instructed.
10. **Links.** Nav/footer links to pages outside the five built pages point to `#`.
11. **Photos.** Unsplash photos are downloaded into `src/assets/photos/` (served through Astro's image pipeline) and credited in `docs/CREDITS.md`. Where the reference shows product UI inside a media inset, an Unsplash photo and/or an original UI-style graphic is used on the same gradient fill.
12. **Canvas colour off the home page.** The style docs give Deep Indigo `#1a2081` as the canvas but were sampled on the home page only. The reference download and quests pages measure black with blurple glows, so those pages use black (`--color-black` token). Home keeps Deep Indigo.
13. **Per-page metrics the docs did not sample.** Download/quests headings (72px and 48px, tighter tracking) and their compact 48–52px buttons use measured reference values, since those elements do not exist on the home page the docs were taken from.
14. **Measured exceptions to the docs' "no shadows / no borders" rule.** Kept only where the reference measurably has them on states or elements the docs did not sample (button hover shadows, menu divider lines, a tablet button ring). Each is noted in the owning component.
15. **Preview pages.** Per-section preview pages moved to `src/pages/_preview/` so they are not part of the production build.
16. **Generic star layers removed** from the home and quests heroes during QA (the reference heroes carry only their measured twinkle stars / none); the page starfield was retuned to the reference's dim lavender tone.
